 # MindFlow 智流日志 - 产品规划文档

 > 基于 MindFlow 智流日志的 AI 增强型工作学习日志系统

 ---

 ## 一、产品概述

 ### 1.1 产品名称
 **MindFlow 智流日志** - 让知识流动，让成长可见

 ### 1.2 产品定位
 基于 MindFlow 开源项目打造的**AI 增强型个人知识管理系统**，专注于工作日志、学习记录与每日复盘，通过 AI 自动生成结构化 Markdown 文档，帮助用户构建可检索、可积累的个人知识库。

 ### 1.3 目标用户
 | 用户类型 | 特征描述 | 核心痛点 |
 |---------|---------|---------|
 | **知识工作者** | 程序员、产品经理、设计师等 | 每天大量工作内容难以系统化沉淀 |
 | **终身学习者** | 在校学生、自学者、备考人群 | 学习笔记零散，缺乏有效的复习和总结机制 |
 | **个人成长者** | 职场人士、自由职业者 | 需要每日复盘但缺乏工具和方法论 |

 ### 1.4 产品愿景
 > "记录即成长，复盘即进步，知识即资产"

 ## 二、竞品分析

 ### 2.1 竞品矩阵

 | 产品 | 定位 | 优势 | 劣势 | 与我们的差异 |
 |------|------|------|------|-------------|
 | **Notion** | 全能协作工具 | 功能强大、生态丰富、团队协作 | 学习曲线陡、数据在云端、订阅制 | 我们专注个人场景，本地优先，AI 原生 |
 | **Obsidian** | 本地知识管理 | 本地存储、双向链接、插件生态 | 配置复杂、缺乏 AI、移动端弱 | 我们开箱即用，AI 自动化，移动端友好 |
 | **Logseq** | 开源大纲笔记 | 开源免费、隐私友好、大纲式 | 同步困难、社区小、功能迭代慢 | 我们继承开源优势，增强 AI 和移动端 |
 | **Day One** | 日记应用 | 体验优雅、自动元数据、多媒体 | 功能单一、无 AI、订阅制 | 我们扩展为知识系统，加入 AI 复盘 |
 | **Flomo** | 轻量笔记 | 极简、标签系统、API 开放 | 功能有限、无 AI、付费 | 我们提供更完整的日志+AI 体系 |
 | **飞书文档** | 团队协作 | 团队功能强、AI 集成 | 企业场景重、个人使用受限 | 我们专注个人场景，更轻量灵活 |

 ### 2.2 市场机会

 1. **AI 赋能个人知识管理是蓝海**：现有产品要么强于记录但缺 AI（Obsidian），要么强于 AI 但场景泛化（Notion AI）
 2. **本地优先+AI 的组合稀缺**：隐私敏感用户对云端 AI 存在顾虑，本地处理+可选云端 AI 是差异化机会
 3. **工作学习场景垂直化**：通用笔记工具缺乏对"每日复盘"、"学习记录"等场景的深度优化

 ### 3.2 详细功能规格

 #### 3.2.1 智能日志系统

 **工作日志模块**
 - 任务记录：支持任务创建、状态追踪（进行中/完成/阻塞）
 - 进度记录：支持 Markdown 格式的详细工作描述
 - 成果展示：支持代码片段、截图、文件附件
 - 时间追踪：自动记录工作时长统计
 - 项目标签：支持多项目分类管理

 **学习笔记模块**
 - 知识点结构化：支持标题、要点、示例的层次结构
 - 难点标注：标记需要深入学习的知识点
 - 关联笔记：与历史笔记建立关联
 - 学习时长：记录学习投入时间
 - 掌握程度：自评掌握水平（了解/理解/掌握/精通）

 **灵感速记模块**
 - 快速输入：一键唤起，支持快捷键（Ctrl/Cmd + N）
 - 语音输入：支持语音转文字（需要浏览器支持）
 - 图片 OCR：支持图片文字识别
 - 标签分类：快速添加标签便于后续整理

 #### 3.2.2 AI 复盘引擎（核心差异化）

 **每日智能总结**
 - 自动汇总当日所有记录
 - 生成结构化总结（工作成果、学习收获、待改进点）
 - 支持自定义总结模板
 - 可选择 AI 模型（本地小模型/云端大模型）

 **知识点提取**
 - 从工作和学习记录中自动提取关键知识点
 - 生成知识点卡片，便于回顾
 - 识别重复出现的知识点，标记为重点

 **行动项识别**
 - 自动识别记录中的待办事项
 - 识别承诺和约定
 - 生成明日行动清单
 - 支持导出到任务管理工具

 **成长洞察**
 - 分析工作模式和效率变化
 - 识别学习偏好和知识盲区
 - 生成周度/月度成长报告
 - 提供个性化改进建议

 #### 3.2.3 知识库系统

 **MD 文档自动生成**
 - 每日自动生成结构化 Markdown 文件
 - 支持自定义文档模板
 - 自动生成目录和索引
 - 支持导出到 Obsidian/Logseq 等工具

 **知识图谱**
 - 可视化知识节点之间的关联
 - 支持手动建立关联
 - 自动发现潜在关联
 - 支持缩放和筛选

 **智能标签**
 - AI 自动推荐标签
 - 支持层级标签（如：编程/前端/Vue）
 - 标签统计和趋势分析
 - 标签合并和重命名

 **全文检索**
 - 支持中文分词搜索
 - 支持正则表达式
 - 搜索结果高亮
 - 搜索历史记录

 ## 四、技术架构

 ### 4.1 基于 MindFlow 的技术栈升级

 | 层级 | 现有方案 | 升级方案 | 说明 |
 |------|---------|---------|------|
 | **前端框架** | Vue 3 + Vite | Vue 3 + Vite + Pinia | 迁移 Vuex 到 Pinia，更好的 TypeScript 支持 |
 | **桌面端** | Electron 33 | Electron 33 + Capacitor | 保持桌面端，增加移动端能力 |
 | **数据存储** | IndexedDB (LocalForage) | SQLite + IndexedDB | SQLite 支持更复杂查询，IndexedDB 作为缓存 |
 | **富文本编辑** | Quill | Tiptap (ProseMirror) | 更现代，更好的扩展性 |
 | **AI 集成** | 无 | LangChain.js + Ollama | 支持本地模型和云端 API |
 | **Markdown** | 基础支持 | markdown-it + 双向链接 | 完整 Markdown 生态 |
 | **图表可视化** | Chart.js | ECharts / D3.js | 更强大的可视化能力 |

 ## 五、AI Prompt 设计

 ### 5.1 每日复盘 Prompt 模板

 ```markdown
 ## 角色
 你是一位专业的个人成长教练和知识管理专家。

 ## 任务
 基于用户今天的工作日志和学习记录，生成一份结构化的每日复盘总结。

 ## 输入数据
 - 工作记录：{work_logs}
 - 学习笔记：{learning_notes}
 - 灵感速记：{sparks}
 - 元数据：心情 {mood}，精力 {energy}/10，效率 {productivity}/10

 ## 输出要求
 请按以下结构生成总结：

 ### 📋 今日成果
 - 列出完成的主要工作成果（3-5 条）
 - 标注重要程度（高/中/低）

 ### 📚 学习收获
 - 提取关键知识点（带简要说明）
 - 标注掌握程度

 ### 💡 核心洞察
 - 今天最重要的 1-2 个领悟或发现

 ### ⚡ 待改进点
 - 识别效率瓶颈或知识盲区

 ### ✅ 明日行动
 - 基于今天的记录，生成 3-5 条具体可行的行动项

 ### 🔗 关联知识
 - 识别与历史记录的关联点

 ## 格式要求
 - 使用 Markdown 格式
 - 语言简洁有力
 - 重点内容加粗
 ```

 ### 5.2 知识点提取 Prompt

 ```markdown
 ## 角色
 你是一位知识管理专家，擅长从非结构化文本中提取结构化知识。

 ## 任务
 从以下记录中提取有价值的知识点。

 ## 输入
 {raw_content}

 ## 输出格式
 对每个知识点：
 1. **标题**：简明扼要的知识点名称
 2. **内容**：2-3 句话的核心解释
 3. **标签**：相关领域标签（1-3 个）
 4. **关联**：可能相关的已有知识点（如有）
 5. **重要性**：高/中/低

 ## 要求
 - 聚焦于可复用、可迁移的知识
 - 避免记录临时性、一次性信息
 - 优先提取方法论、原则、模式类知识
 ```

 ## 附录 A：MindFlow 代码分析

 ### 现有优势（可直接复用）
 1. **本地优先架构**：IndexedDB 存储，离线可用
 2. **数据备份系统**：版本化导入导出，冲突解决
 3. **组件化设计**：清晰的 Vue 组件结构
 4. **国际化支持**：中英文切换
 5. **主题系统**：深浅色模式
 6. **快捷键系统**：可扩展的快捷键框架

 ### 需要改进的部分
 1. **状态管理**：Vuex 迁移到 Pinia
 2. **编辑器**：Quill 功能有限，需升级
 3. **数据模型**：缺乏工作/学习场景的结构化数据
 4. **AI 能力**：完全缺失
 5. **知识管理**：缺乏知识图谱和关联功能
 6. **检索能力**：基础搜索需增强
