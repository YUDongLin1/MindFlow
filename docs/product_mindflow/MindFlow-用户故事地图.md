## 一、用户旅程总览

```
新用户 → 首次记录 → 日常使用 → 成长回顾 → 知识沉淀 → 持续使用
  │         │          │          │          │          │
  ▼         ▼          ▼          ▼          ▼          ▼
安装应用   写第一篇    每日记录    周/月回顾   知识库     长期习惯
了解功能   体验AI复盘  使用待办    生成周报    AI问答     数据积累
选择模块   添加标签    语音输入    查看统计    双链图谱   自定义模块
```

## 二、用户角色

### 角色 A：知识工作者 — 小明

- **年龄**: 28 岁
- **职业**: 产品经理
- **场景**: 每天需要记录工作内容、复盘项目进展
- **痛点**: 工具分散（Notion 记工作、备忘录记生活、日记本记心情）
- **需求**: 统一入口、AI 辅助整理、可导出 Markdown

### 角色 B：学生 — 小红

- **年龄**: 22 岁
- **职业**: 研究生
- **场景**: 学习新知识、写论文、记录灵感
- **痛点**: 笔记散落各处、复习没有系统
- **需求**: 双链知识库、间隔复习、学习笔记模板

### 角色 C：自我成长者 — 小李

- **年龄**: 30 岁
- **职业**: 自由职业
- **场景**: 关注个人成长、情绪管理、习惯养成
- **痛点**: 坚持不下去、缺少反馈
- **需求**: 每日总结、AI 鼓励、进度可视化

### 角色 D：隐私敏感用户 — 小王

- **年龄**: 35 岁
- **职业**: 软件工程师
- **场景**: 不信任云端服务、数据要自己掌控
- **痛点**: 云端日记有泄露风险
- **需求**: 纯本地存储、开源可审计、数据可导出

## 三、用户故事地图

### 第一层：主干活动（Backbone）

| 阶段 | 活动 | 描述 |
|------|------|------|
| **入门** | 安装与首次使用 | 下载安装、了解界面、写第一篇记录 |
| **日常** | 每日记录 | 选择模块、填写内容、添加标签、保存 |
| **日常** | AI 复盘 | 触发复盘、查看结果、采纳/丢弃 |
| **日常** | 待办管理 | 添加待办、勾选完成、查看进度 |
| **回顾** | 周回顾 | 查看本周统计、生成工作周报 |
| **回顾** | 月回顾 | 查看月度数据、热力图、标签分析 |
| **知识** | 知识浏览 | 按时间线浏览、搜索过滤、导出 |
| **知识** | 知识问答 | 自然语言提问、获取回答 |
| **知识** | 知识复习 | 间隔重复复习重要记录 |
| **管理** | 数据管理 | 导出备份、导入迁移、路径管理 |
| **个性化** | 设置定制 | 主题/语言/模块/宠物自定义 |

## 六、关键用户流程

### 流程 1：新用户首次使用

```
安装应用
  ↓
打开 MindFlow
  ↓
看到今日记录页面（空状态）
  ↓
阅读引导提示："从三句话开始，不空白、不费力"
  ↓
选择记录模块（默认日记）
  ↓
填写三个问题
  ↓
添加标签（可选）
  ↓
点击「保存这条记录」
  ↓
看到记录出现在下方列表
  ↓
点击「AI 复盘」
  ↓
查看 AI 生成的四段结构
  ↓
点击「采纳」或「丢弃」
  ↓
完成首次使用
```

### 流程 2：每日日常使用

```
打开 MindFlow
  ↓
查看今日待办（勾选已完成的）
  ↓
查看每日总结卡片
  ↓
与桌面宠物互动
  ↓
选择今日模块
  ↓
填写记录内容
  ↓
触发 AI 复盘
  ↓
采纳/编辑复盘结果
  ↓
添加新待办（如果有）
  ↓
关闭应用（数据自动保存）
```

### 流程 3：周回顾

```
点击侧边栏「成长」
  ↓
查看周回顾统计卡片
  ↓
阅读自动生成的本周叙事
  ↓
查看记录分布柱状图
  ↓
查看模块分布和标签 Top 5
  ↓
点击「生成本周工作周报」
  ↓
复制或下载周报
  ↓
（可选）切换到月回顾查看更大维度
```

### 流程 4：知识检索

```
点击侧边栏「知识库」
  ↓
方式一：在搜索框输入关键词
  ↓
查看过滤后的记录列表
  ↓
点击条目查看 Markdown 预览

方式二：点击「知识库问答」
  ↓
输入自然语言问题
  ↓
查看 AI 生成的回答
  ↓
点击相关记录查看详情
```

### 流程 5：数据备份与迁移

```
点击侧边栏「设置」
  ↓
找到「数据管理」区块
  ↓
点击「导出 JSON」创建完整备份
  ↓
备份文件保存到本地

--- 在新设备上 ---

安装 MindFlow
  ↓
点击「导入」
  ↓
选择之前的 JSON 备份文件
  ↓
预览导入内容和冲突
  ↓
选择处理策略（跳过/覆盖/追加）
  ↓
确认导入
  ↓
数据恢复完成
```
