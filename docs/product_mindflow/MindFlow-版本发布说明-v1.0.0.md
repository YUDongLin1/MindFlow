# MindFlow 智流日志 v1.0.0 — 版本发布说明

> **发布日期**: 2026-08-06  
> **版本号**: 1.0.0  
> **开源协议**: AGPL-3.0

---

## 版本亮点

### 🎯 核心功能

**三合一记录系统**
- 日记、工作日志、学习笔记统一入口
- 每种模块专属三问模板，降低记录门槛
- 支持自定义记录模块，匹配个人工作流

**AI 智能复盘**
- 四段结构化复盘：今日成果 / 学习收获 / 待改进 / 明日行动
- 三种 AI 模式：本地镜像（离线） / 自带 Key / 云端
- 溯源校验：确保 AI 不编造，每段内容可回溯到原文
- 设计红线：绝不静默定稿，标注「草稿·需你确认」

**知识自动沉淀**
- 每条记录自动生成 Markdown（含 frontmatter + 双链）
- 知识树按年/月分层浏览
- AI 知识库问答：自然语言检索记录
- 双链图谱可视化：发现知识之间的连接
- 间隔重复复习（SM-2 算法）

### 📊 成长回顾

**周回顾**
- 复盘完成度环形图
- 记录分布柱状图（周一至周日）
- 模块分布 + 标签 Top 5
- 自动生成本周叙事
- 一键生成工作周报

**月回顾**
- 月统计卡片（记录数/活跃天数/总字数/复盘采纳）
- 每日记录热力图
- 模块分布 + 标签 Top 10
- 待办完成统计 + 进度条

### 📅 日历视图

- 月历网格 + 记录指示点
- 点击日期查看/编辑当日记录
- 月统计（总记录/日记/工作/学习）
- 当日待办显示

### ✅ 待办管理

- 每日待办事项（CRUD + 优先级）
- 进度条显示完成率
- 日历中显示当日待办
- 30天自动清理已完成待办

### 🔒 隐私与数据

- 纯本地存储（IndexedDB），离线可用
- 数据存储路径查看和修改
- JSON/CSV/Markdown 三格式导出
- 5 格式无损导入（JSON/微信小记/备忘录/Notion）
- AI 连接测试
- AI 审计日志

### 🎨 个性化

- 主题切换：暖阳（浅色）/ 夜幕（深色）/ 追随系统
- 中英文国际化
- 桌面宠物：猫/狗/植物/自定义 + 每日语录 + 鼓励语
- 自定义记录模块：名称/字段/标签自由配置

### ⚡ 便捷功能

- 富文本编辑器（Tiptap）：粗体/斜体/列表/引用/代码块/链接
- 语音输入（Web Speech API + 中文识别）
- 智能标签推荐（TF-IDF 算法）
- 元数据自动记录（时间/地点/天气）
- 全局快捷键（Ctrl+N/F/,/S/E 等）
- 使用时间监控（MindFlow + 外部应用）

## 数据迁移

### 从其他应用迁移

支持从以下来源导入：
- **JSON**: MindFlow/MindFlow 完整备份
- **TXT**: 微信小记
- **TXT/HTML**: 苹果备忘录
- **CSV**: Notion 导出
- **Markdown**: Notion 导出

导入路径：设置 → 数据管理 → 导入
