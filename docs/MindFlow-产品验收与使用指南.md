 ## 二、Windows 安装与使用

 ### 2.1 安装方法

 #### 方法一：安装版（推荐）
 
 1. 双击 `MindFlow Setup 1.0.0.exe`
 2. 按照安装向导提示完成安装（assisted 安装器，**可自选安装路径**，不再强制安装到默认目录）
 3. 安装完成后，桌面会创建快捷方式
 4. 双击桌面图标即可启动
 
 #### 方法二：便携版（免安装）
 
 1. 双击 `MindFlow 1.0.0.exe` 直接运行
 2. 无需安装，适合放在 U 盘随身携带
 
 #### 使用时长功能说明（桌面端）
 
 桌面端内置**全电脑应用使用时长**统计（含周末与节假日、空闲检测）：
 
 - 「今日」页的使用时长卡片展示 MindFlow 自身活跃时间与当日外部应用使用排行（每 30 秒刷新）
 - 统计口径为前台窗口采样（行业通行做法）：仅累计处于前台的应用时间，空闲/锁屏/休眠不计入
 - 数据按本地日期持久化（`usage/usage-YYYY-MM-DD.json`），覆盖周末与节假日

 ### 2.2 首次使用指南

 #### 第一步：创建第一条记录

 1. 打开 MindFlow 后，进入「今日」页面
 2. 选择记录类型：**日记** / **工作日志** / **学习笔记**
 3. 按照引导问题填写内容：
    - 日记三问：今天最值得记住的 / 此刻的心情 / 想记住的一句话
    - 工作三字段：做了什么 / 卡在哪里 / 下一步
    - 学习三维度：学到了什么 / 哪里没懂 / 想深挖的点
 4. 点击「保存」或使用快捷键 `Ctrl + S`

 #### 第二步：体验 AI 复盘

 1. 写完记录后，点击页面底部的「AI 复盘」按钮
 2. AI 会生成四段式总结：
    - 📋 **今日成果**：完成的主要工作
    - 📚 **学习收获**：关键知识点
    - ⚡ **待改进点**：效率瓶颈或知识盲区
    - ✅ **明日行动**：具体可行的行动项
 3. 你可以**编辑 / 采纳 / 丢弃 / 还原** AI 的输出
 4. 所有 AI 操作都有审计日志

 #### 第三步：配置 AI（可选）

 1. 进入「隐私设置」页面
 2. 选择 AI 模式：
    - **本地镜像**：零网络，基于规则的模板（默认）
    - **自带 Key**：支持 OpenAI 兼容 API + Ollama
    - **云端**：订阅制云端模型服务
 3. 如果选择「自带 Key」：
    - 填入 API Key
    - 填入 BaseURL（如 `https://api.openai.com/v1`）
    - 填入模型名称（如 `gpt-4o-mini`）
    - Ollama 用户：BaseURL 填 `http://localhost:11434`，无需 Key

 #### 第四步：探索知识库

 1. 进入「知识库」页面
 2. 查看自动生成的 Markdown 文件（按年月组织）
 3. 使用 `[[双链]]` 标记关键词，建立知识关联
 4. 点击「图谱」查看知识网络可视化
 5. 使用「复习队列」进行间隔重复学习

 ### 2.3 快捷键速查

 | 快捷键 | 功能 | 说明 |
 |--------|------|------|
 | `Ctrl + N` | 新建记录 | 全局生效，跳转「今日」页 |
 | `Ctrl + S` | 保存当前记录 | 今日页内生效，编辑器聚焦时也可用 |
 | `Ctrl + F` | 全局搜索 | 全局生效，跳转知识库并自动聚焦搜索框 |
 | `Ctrl + E` | 切换富文本/纯文本 | 今日页内生效 |
 | `Ctrl + D` | 插入当前日期 | 纯文本模式下，插入到光标处 |
 | `Ctrl + L` | 插入双链 `[[]]` | 纯文本模式下，光标自动移入括号中间 |
 | `Ctrl + Shift + A` | 触发 AI 复盘 | 今日页内生效，展开最新一条记录的复盘 |
 | `Ctrl + ,` | 打开设置 | 全局生效 |

 > macOS 下 `Ctrl` 对应 `⌘ (Cmd)`。

 ### 2.4 数据管理

 #### 导出数据

 1. 进入「设置」→「数据管理」
 2. 三种导出格式任选：
    - **JSON 完整备份**：全部条目 + AI 偏好 + 审计日志，可重新导入恢复（API Key 已脱敏，不导出明文）
    - **CSV 表格**：UTF-8 带 BOM，Excel 直接打开不乱码
    - **Markdown 知识库**：单文件全量导出，带 frontmatter + 双链，Obsidian 可直接打开
 3. 点击对应按钮即自动下载到本地

 #### 导入数据

 1. 进入「设置」→「数据管理」→「开始导入」
 2. 支持 5 种格式自动识别：
    - MindFlow JSON 备份（上面导出的文件可直接回导）
    - MindFlow JSON 备份
    - 纯文本 (.txt，微信小记/备忘录)
    - CSV 表格 / Markdown 文档（Notion 导出）
    - HTML 网页
 3. 系统会自动检测冲突并提供预览
 4. 选择合并策略：合并 / 替换 / 跳过

 ## 三、产品介绍（对外宣传版）

 ### 3.1 一句话定位

 > **MindFlow 智流日志** —— 本地优先的 AI 个人成长记录中心
 >
 > 记录、复盘、沉淀，三位一体。

 ### 3.2 核心卖点

 #### 🪞 卖点 1：AI 是镜子，不是写手

 MindFlow 的 AI 复盘遵循「镜子原则」——它映照你的记录，提炼结构化洞察，但绝不替你定稿。每一句 AI 输出都标注「草稿·需你确认」，你可以编辑、采纳、丢弃或还原为原文。所有 AI 操作都有完整审计日志，溯源校验防止幻觉内容。

 #### 📦 卖点 2：三合一不割裂

 工作日志（做了什么/卡在哪里/下一步）、学习笔记（学到了什么/哪里没懂/想深挖的点）、生活日记（今天值得记住的/此刻的心情/想记住的一句话）——三种记录模板各有引导，但统一存储、统一检索、统一复盘。知识自然沉淀，不需要刻意整理。

 #### 📚 卖点 3：自动沉淀的可带走知识库

 每条记录自动生成带 frontmatter 和双链 `[[ ]]` 的 Markdown 文件，按年月组织成文件树。你可以一键导出整个知识库，用 Obsidian、VS Code 或任何 Markdown 编辑器打开——你的知识永远属于你。

 #### 🧠 卖点 4：间隔重复 + 知识图谱

 学习笔记用 `[[双链]]` 标记关键词，自动加入间隔重复队列。SM-2 算法根据你的记忆强度动态调整复习间隔。知识图谱以 Canvas 力导向图可视化所有条目和标签的引用关系，一目了然地看到知识网络。

 #### 🔒 卖点 5：隐私透明可控

 三种 AI 模式（本地/自带 Key/云端）完全由你选择。本地模式零网络、零数据外泄。自带 Key 模式支持 OpenAI 兼容 API 和 Ollama 本地模型。所有 AI 操作有审计日志，溯源校验防止幻觉。数据 100% 存储在本地 IndexedDB，不上传、不训练。

 #### ✨ 卖点 6：首屏零空白

 打开应用就是「今天三句话」——不是空白页让你无从下手，而是三个温柔的引导问题。0 秒写出第一条记录，AI 即时复盘给你反馈。语音输入让你不用打字也能记录。智能标签自动推荐，不需要手动分类。

 #### 🎨 卖点 7：「纸·墨·流」设计语言

 安静的纸感背景、深墨字、单一流青强调色——没有 AI 紫蓝渐变、没有玻璃拟态堆砌、没有霓虹效果。大量留白，编辑式排版。浅色/深色主题一键切换，所有颜色通过 CSS 变量通道化定义，确保明暗主题一致的视觉体验。

 ### 3.3 目标用户画像

 | 用户类型 | 痛点 | MindFlow 解决方案 |

 ## 五、常见问题

 ### Q1: AI 复盘需要联网吗？

 **A:** 取决于你选择的 AI 模式：
 - **本地镜像**：完全离线，基于规则的模板
 - **自带 Key**：需要联网调用 API（或本地 Ollama）
 - **云端**：需要联网

 ### Q2: 数据会上传到服务器吗？

 **A:** 不会。所有数据 100% 存储在本地 IndexedDB，不上传、不训练。AI 调用时仅发送当日记录作为上下文，不存储在云端。

 ### Q3: 支持多设备同步吗？

 **A:** 当前版本支持一键导出/导入实现手动同步。M3b 版本将支持 E2EE 加密同步。

 ### Q4: 可以导入其他笔记应用的数据吗？

 **A:** 支持导入 5 种格式：JSON、TXT、CSV、Markdown、HTML。系统会自动识别格式并处理冲突。

 ### Q5: 如何备份数据？
