## 一、产品定位

MindFlow 智流日志是一款**本地优先、隐私开源、AI 驱动**的个人成长记录中枢。它将日记、工作日志、学习笔记三合一，配合 AI 自动复盘和自动生成的 Markdown 知识库，帮助用户建立「记录 → 复盘 → 沉淀」的成长闭环。

**一句话定位**：本地优先的 AI 个人成长记录中枢——记录、复盘、沉淀，三位一体。

### 核心理念

| 理念 | 说明 |
|------|------|
| **AI 是镜子，不是写手** | AI 复盘以「草稿·需你确认」呈现，绝不静默定稿，采纳/丢弃/还原三态齐备 |
| **数据 100% 归你** | 所有数据存储在本地 IndexedDB，不上传、不训练模型，一键无损导出 |
| **三合一不割裂** | 工作日志、学习笔记、生活日记统一入口，自动归类，知识自然沉淀 |
| **无打卡羞辱** | 不做醒目连续打卡 UI，温和叙事替代数字审判 |

## 二、功能全景

### 2.1 今日 — 首屏零空白的记录入口

| 功能 | 说明 |
|------|------|
| **三模块切换** | 日记 · 工作日志 · 学习笔记，每种模板独立引导（日记三问 / 工作三字段 / 学习三维度） |
| **富文本编辑器** | 基于 Tiptap 的 WYSIWYG 编辑器，支持粗体/斜体/下划线/链接/列表/引用/代码块/标题 |
| **纯文本/富文本切换** | 一键切换输入模式，适应不同记录习惯 |
| **语音输入** | Web Speech API 中文连续识别，实时转写，录音动画反馈 |
| **智能标签推荐** | 基于 TF-IDF 中文分词 + 滑动窗口词组提取，实时推荐标签 |
| **自动元数据** | 自动记录当前时间、地理位置（Nominatim 反向编码）、天气（wttr.in） |
| **AI 复盘** | 四段结构化复盘（今日成果/学习收获/待改进/明日行动），支持三模式 AI |
| **每日待办** | 快速添加/勾选完成/优先级标记/进度条，数据持久化 |
| **每日总结卡片** | 当日条目聚合统计（条目数/字数/标签/心情/模块分布/关键片段/去年今日对比） |
| **自定义记录模块** | 支持自定义字段与图片附件，AI 复盘同样生效 |
| **桌面宠物** | 预设猫/狗/植物 + 自定义上传，点击互动、每日语录与待办提醒 |

### 2.2 成长 — 温和的数据映照

| 功能 | 说明 |
|------|------|
| **周回顾卡片** | 复盘完成度环形图、模块分布柱状图、标签 Top5、温和叙事文案 |
| **周报生成** | 一键聚合本周工作日志，生成结构化 Markdown 工作周报，支持复制/下载 |
| **统计磁贴** | 累计记录数、坚持天数、平均能量等关键指标 |
| **无打卡羞辱** | 不显示连续打卡天数的醒目数字，避免心理压力 |

### 2.3 知识库 — 自动沉淀的可带走资产

| 功能 | 说明 |
|------|------|
| **Markdown 知识树** | 按年月分组的文件树，每条记录自动生成带 frontmatter + 双链 `[[ ]]` 的 Markdown |
| **全文检索** | 搜索内容、标签、日期，结果高亮 |
| **预览/复制/下载** | 单条或批量导出，支持 Obsidian/VS Code 直接打开 |
| **知识图谱** | Canvas 力导向可视化，节点（条目/标签）+ 边（引用关系），点击查看详情 + 反向链接列表 |
| **间隔重复复习** | SM-2 算法驱动，卡片翻转 + 4 级评分（忘了/模糊/记得/熟练），自动计算下次复习时间 |
| **AI 问答** | 基于所有记录的智能问答，关键词检索 + AI 生成回答，AI 不可用时退化为纯搜索 |
| **复习队列** | 学习笔记中用 `[[双链]]` 或标记按钮加入，支持批量复习 |

### 2.4 日历 — 按日期浏览记录

| 功能 | 说明 |
|------|------|
| **月历网格** | 显示每日是否有记录（圆点标识），支持左右翻月、跳转今天 |
| **点击查看详情** | 点击某天查看该日所有条目（日记/工作/学习）+ AI 复盘标识 |
| **月统计面板** | 总记录数、日记/工作/学习分布 |
| **时区修正** | 使用本地时间（非 UTC），消除跨时区日期偏移问题 |

### 2.5 隐私 — 数据主权透明可控

## 三、AI 能力详解

### 3.1 AI 复盘（核心功能）

```
[记录] 今日三问/工作日志/学习笔记
   ↓ [触发] 手动点击 / 自动
   ↓ [AI] 读取当日记录 → 生成四段结构化复盘
   ↓ [复盘] 今日成果 | 学习收获 | 待改进 | 明日行动
   ↓ [用户] 编辑 / 采纳 / 丢弃 / 还原
   ↓ [沉淀] 落入当日条目
```

**安全约束**：
- 所有 AI 输出标注「草稿·需你确认」
- 溯源校验：shingle(n=3) 覆盖率 ≥ 0.35
- 失败回退：网络错误自动降级为本地镜像 + 审计记录
- 12 秒超时保护

### 3.2 AI 三模式

| 模式 | 说明 | 适用场景 |
|------|------|---------|
| **本地镜像** | 零网络，基于规则的结构化模板 | 隐私敏感、离线环境 |
| **自带 Key** | OpenAI 兼容 API + Ollama 自动探测 | 个人部署、本地模型 |
| **云端** | 订阅云端模型服务 | 便捷使用 |

### 3.3 AI 问答

基于所有历史记录的智能问答：
1. 关键词检索匹配相关条目（TF-IDF 排序，Top 5）
2. 拼接上下文调用 AI 生成回答
3. AI 不可用时退化为纯关键词搜索结果

## 五、设计系统 — 「纸·墨·流」

### 设计原则

| 原则 | 说明 |
|------|------|
| **纸感背景** | 极淡的暖色调纸张质感，非纯白 |
| **深墨字** | 高对比度深色文字，清晰易读 |
| **单一流青强调** | 低饱和度的青绿色作为唯一强调色 |
| **去 AI 味** | 严禁 AI 紫蓝渐变、霓虹效果、玻璃拟态堆叠 |
| **克制留白** | 大量呼吸空间，编辑式排版 |

### 色彩系统

```css
/* 浅色（纸） */
--paper: 250 247 241;      /* 纸张底色 */
--surface: 255 255 255;    /* 卡片表面 */
--ink: 35 43 38;           /* 主文字 */
--accent: 47 126 110;      /* 流青强调色 */

/* 深色（墨） */
--paper: 21 25 21;         /* 深色底 */
--surface: 30 36 30;       /* 深色卡片 */
--ink: 233 237 231;        /* 浅色文字 */
--accent: 87 160 145;      /* 浅色流青 */
```

所有颜色以 RGB 通道变量定义，支持 Tailwind 透明度修饰符和明暗主题双写。

## 七、产品亮点

### 亮点 1：AI 是镜子，不是写手

MindFlow 的 AI 复盘设计遵循「镜子原则」——它映照你的记录，提炼结构化洞察，但绝不替你定稿。每一条 AI 输出都标注「草稿·需你确认」，你可以编辑、采纳、丢弃或还原为原文。所有 AI 操作都有完整审计日志，溯源校验防止幻觉内容。

### 亮点 2：三合一不割裂

工作日志（做了什么/卡在哪里/下一步）、学习笔记（学到了什么/哪里没懂/想深挖的点）、生活日记（今天值得记下的/此刻的心情/想记住的一句话）——三种记录模板各有引导，但统一存储、统一检索、统一复盘。知识自然沉淀，不需要刻意整理。

### 亮点 3：自动沉淀的可带走知识库

每条记录自动生成带 frontmatter 和双链 `[[ ]]` 的 Markdown 文件，按年月组织成文件树。你可以一键导出整个知识库，用 Obsidian、VS Code 或任何 Markdown 编辑器打开——你的知识永远属于你。

### 亮点 4：间隔重复 + 知识图谱

学习笔记用 `[[双链]]` 标记关键词，自动加入间隔重复队列。SM-2 算法根据你的记忆强度动态调整复习间隔。知识图谱以 Canvas 力导向图可视化所有条目和标签的引用关系，一目了然地看到知识网络。

### 亮点 5：隐私透明可控

三种 AI 模式（本地/自带 Key/云端）完全由你选择。本地模式零网络、零数据外泄。自带 Key 模式支持 OpenAI 兼容 API 和 Ollama 本地模型。所有 AI 操作有审计日志，溯源校验防止幻觉。数据 100% 存储在本地 IndexedDB，不上传、不训练。

### 亮点 6：首屏零空白

打开应用就是「今天三句话」——不是空白页让你无从下手，而是三个温柔的引导问题。30 秒写出第一条记录，AI 即时复盘给你反馈。语音输入让你不用打字也能记录。智能标签自动推荐，不需要手动分类。

### 亮点 7：温和叙事，无打卡羞辱

没有醒目的连续打卡天数，没有「你已经断签 X 天」的审判式提示。周回顾用温和的叙事文案和完成度环形图替代数字惩罚。每一步记录都有价值，不需要完美坚持。

### 亮点 8：「纸·墨·流」设计语言

安静的纸感背景、深墨字、单一流青强调色——没有 AI 紫蓝渐变、没有玻璃拟态堆叠、没有霓虹效果。大量留白，编辑式排版。浅色/深色主题一键切换，所有颜色通过 CSS 变量通道化定义，确保明暗主题一致的视觉体验。

## 九、快速开始

### 安装与运行

```bash
# 说明：MindFlow 暂无独立公开仓库（package.json 的 repository/bugs 仍指向上游
# MindFlow/MoodsNote），以下命令均在项目根目录执行

# 安装依赖
npm install

# 开发模式（Electron 桌面端）
npm run dev

# 仅前端预览
npx vite build
npx vite preview

# 生产构建与打包
npm run build          # 前端 + Electron TypeScript 编译
npm run package:win    # 打包 Windows，产物输出至 dist-electron/

# 配置真实 AI（可选）
# byok 模式：在「隐私」页填入 API Key + BaseURL + Model
# Ollama：BaseURL 填 http://localhost:11434，无需 Key
# cloud：.env 设置 VITE_MINDFLOW_LLM_ENDPOINT
```

### 系统要求

- Node.js ≥ 18
- npm ≥ 9
- 支持 macOS / Windows / Linux
